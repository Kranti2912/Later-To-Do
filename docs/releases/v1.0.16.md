# Later 1.0.16

## What changed
- Bundled Montserrat so task text looks consistent without requiring a system font install.
- Added translucent glass styling to the peek button and expanded panel.

## Known issue
On some Windows systems, the native Acrylic material appeared as a rectangular backdrop outside the rounded peek button. Version 1.0.17 removes that whole-window material from peek mode.

## Download
Download `Later-Setup-1.0.16.exe` from the release assets. Version 1.0.17 includes the peek backdrop fix.
