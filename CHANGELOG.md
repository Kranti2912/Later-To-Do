# Changelog

## 1.0.15

- Let the peek button move freely while dragging, then dock it to the nearest screen edge when released.
- Preserve the selected edge and along-edge position across restarts.

Notable user-facing changes are listed here. Git tags identify complete source snapshots; release notes for a version do not imply that a separate historical source snapshot is available.

## 1.0.14

- Published the current Windows source snapshot and one-click installer.
- Kept peek mode transparent around the rounded button and delayed visibility recovery so screenshot overlays are not interrupted.
- Preserved locally saved tasks when updating.

## 1.0.13

- Increased light-theme surface opacity to 60% and improved contrast for text, labels, borders, and hover states.

## 1.0.12

- Made the system backdrop mode depend on whether the window is expanded or in peek mode.

## 1.0.11

- Improved peek-button hover styling and added non-activating window recovery.

## 1.0.10

- Added translucent glass styling to the peek button and expanded panel.

## 1.0.3

- First locally available historical source snapshot.
- Added the floating task panel, edge-docked peek mode, local task persistence, and theme selection.
