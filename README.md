# Later 1.0.5

This tag preserves the application source shipped in Later 1.0.5. The app files in src/ were recovered from that version's original installer; see ARCHIVE-NOTES.md for provenance and build details.

## Build

Requirements: Node.js 22 and npm.

    npm ci
    npm start
    npm run dist

Pushing this version tag runs the Windows release workflow and creates an installer on the v1.0.5 GitHub Release: https://github.com/Kranti2912/Later-To-Do/releases/tag/v1.0.5

## Data

Only application files are included in this source snapshot. The original installer and any local task data are not committed.
